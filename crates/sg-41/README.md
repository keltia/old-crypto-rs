# SG-41

Historical reconstruction of the German Schlüsselgerät 41.

**Status:** Step 6: typed wheel bank, historical four-phase stepping, and
the 25-bar cage displacement with sixth-wheel inversion. The print-head
character mapping and cipher are not yet implemented; this crate must not
be used for encryption.

See [the technical specification](docs/sg-41.md) and the
[YAML reference fixture](docs/fixtures/sg41-reference.yaml).
